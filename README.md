One line, at most 160 characters, roasting the smart fridge — entered on make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty.

The program writes a single roast line to `/output/entry.txt`:

> My smart fridge knows every item inside it except the leftovers I hid behind the pickles — three grand of AI, outsmarted by a jar.

## Run it

```sh
node main.ts
```

It prints the character count and writes `/output/entry.txt`. Deterministic, no network, no secrets. The line is guarded to 1–160 characters and a single line, matching the competition gate.
